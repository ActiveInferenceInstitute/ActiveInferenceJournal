# data/

Root of all journal content, organized by **type** then **source**:

```
data/video/<source>/      # video-derived content (transcripts, metadata, captions, …)
data/<other-type>/<source>/   # future non-video sources (papers, datasets, …)
```

Currently: [`video/activeinferenceinstitute/`](video/activeinferenceinstitute/) — the
Active Inference Institute YouTube channel.

See [`../docs/ORGANIZATION.md`](../docs/ORGANIZATION.md) for the full namespace model and
[`../docs/SCHEMA.md`](../docs/SCHEMA.md) for the per-item schema. Machine index:
[`../INDEX.json`](../INDEX.json).
