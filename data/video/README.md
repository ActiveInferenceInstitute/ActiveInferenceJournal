# data/video/

Video-derived content, one folder per **source** (channel). Each source holds series →
items following the per-item schema in [`../../docs/SCHEMA.md`](../../docs/SCHEMA.md).

- [`activeinferenceinstitute/`](activeinferenceinstitute/) — the Active Inference Institute channel.

Other channels would be added as sibling folders (`data/video/<channel-slug>/`). See
[`../../docs/ORGANIZATION.md`](../../docs/ORGANIZATION.md).
