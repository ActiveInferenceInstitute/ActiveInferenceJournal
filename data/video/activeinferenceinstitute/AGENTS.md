# Agent guide — activeinferenceinstitute/

One **series** folder per stream type (`GuestStream`, `Roundtable`, `Courses`, …
and `Other` for uncategorized). Each **item** folder is one event with
`metadata.json` (parts = video ids), `transcript.txt/.json`, `captions/`,
`translations/`, `assets/`, `README.md`. Generated by
[Journal-Utilities](https://github.com/ActiveInferenceInstitute/Journal-Utilities);
`metadata.json` is the per-item source of truth. Schema:
[`../../../docs/SCHEMA.md`](../../../docs/SCHEMA.md).
