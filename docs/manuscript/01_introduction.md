# Introduction

A research video can have multiple parts, and a single recording can have machine transcripts, speaker names added by an editor, and translated subtitles. When those are collapsed into one document, it is difficult to trace corrections or decide which component to reuse. The journal packages records by type, source, series, and item. The top-level machine index identifies item paths and video identifiers [@index]; per-item metadata carries the identity information used by the publishing contract [@identity]. The dataset has a public Zenodo record [@dataset].
