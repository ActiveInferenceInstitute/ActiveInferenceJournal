# Implementation evidence

The index at the cited snapshot contains 678 items, 849 part entries, and 845 distinct video identifiers [@index]. These values use three different denominators: the length of the item list, the total number of entries in item part lists, and the cardinality of their union. The raw inventory therefore cannot be read as 849 unique recordings. The corpus schema defines how deliberate secondary records and reconciliation are handled [@schema; @pipeline].

Transcript provenance can be inspected through file shape and metadata: keep the source segments, mapping, and rendered text distinct when deriving a research dataset. This inventory is a single snapshot and provides no estimate of transcription accuracy or translation quality.
